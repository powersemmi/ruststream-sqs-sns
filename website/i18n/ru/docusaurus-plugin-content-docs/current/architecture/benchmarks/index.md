# Бенчмарки

Во что `ruststream-sqs-sns` обходится на каждом сообщении: пропускная способность против сырого
клиента `aws-sdk-sqs`, инструкции и выделения памяти его кода.

## Против сырого клиента {/* #against-a-raw-client */}

Первый график прогоняет каждый сценарий тремя способами на одной и той же конечной
точке SQS. «Сырой
клиент» напрямую работает с `aws-sdk-sqs`. «Крейт брокера» читает подписку этого крейта
собственным циклом, без рантайма. «RustStream» - сервис, который пишет пользователь: обработчик
`#[subscriber]` в приложении. Первая разность показывает, сколько этот крейт стоит поверх клиента,
которого он оборачивает, а вторая - сколько сверху добавляет рантайм.

Каждый цикл изображён полосой от лучшего круга до самого медленного: точка отмечает лучший круг,
засечка - медиану. Ноль оси - лучший круг сырого клиента, и точка правее нуля значит, что цикл
медленнее. Пустая точка отмечает цикл, у которого разница с сырым клиентом меньше разброса кругов.
Таблица под графиком печатает лучший круг, а в скобках медиану.

Оба сценария удаляют каждое сообщение отдельным вызовом `DeleteMessage`, потому что именно это
здесь делает `ack`. Сценарий FIFO распределяет сообщения по 64 группам сообщений, поэтому
придержанная группа никогда не задаёт темп, как показывает страница [Группы](../sqs/fifo.md).

## Стоимость кода {/* #cost-of-the-code */}

Второй график считает, во что обходится одно сообщение на потоке сервиса: инструкции под
callgrind и выделения памяти под DHAT, в установившемся режиме. Каждый сценарий - сервис на
[`SqsBroker`](api:ruststream_sqs_sns::SqsBroker) против той же конечной точки. В счёт входят
диспетчеризация фреймворка и код этого крейта. В него входит и работа AWS SDK на этом потоке:
сборка и подпись каждого запроса, обмен по HTTP и разбор каждого ответа. Эта работа составляет
большую часть каждого числа, поэтому эти числа не сравнимы с числами брокера, клиент которого
работает в собственных потоках. «Холодный старт» - разовая стоимость загрузки конфигурации AWS,
разрешения очереди, чтения её тайм-аута видимости и получения первого сообщения.
