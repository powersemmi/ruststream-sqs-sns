# Группы

Очередь FIFO доставляет каждую группу сообщений по порядку: пока у группы есть сообщение в
обработке, её следующее сообщение ждёт, а другие группы продолжают.

<Diagram name="groups" words={words} />

Каждая отправка в очередь FIFO называет `MessageGroupId`. Сообщения одной группы доставляются в том
порядке, в каком их отправили. Пока сообщение группы в обработке, очередь не выдаёт других
сообщений этой группы. Группа двигается дальше, когда это сообщение удалено или истёк его тайм-аут
видимости. Разные группы друг друга не ждут, поэтому группа - единица параллельной работы.

Каждая отправка также указывает `MessageDeduplicationId`. Отправка, которая повторяет
идентификатор в течение пяти минут, принимается и не доставляется. Очередь с дедупликацией по содержимому выводит
идентификатор из хеша SHA-256 тела, а идентификатор, который называет отправка, имеет приоритет.

Группу публикации этот крейт берёт из самого точного места, которое её называет: из
[`SqsPublishOptions`](api:ruststream_sqs_sns::SqsPublishOptions) вызова, затем из заголовка
[`PARTITION_KEY_HEADER`](api:ruststream_sqs_sns::PARTITION_KEY_HEADER) сообщения, затем из группы,
которую зафиксировала политика, и наконец берёт `default`. Идентификатор дедупликации крейт
отправляет всегда: тот, который называет вызов, или уникальный для процесса. Поэтому две отправки
одного тела - это два сообщения, если сервис не назовёт для обеих один идентификатор. Группу или
идентификатор дедупликации для стандартной очереди крейт отвергает с ошибкой
[`SqsError::NotFifo`](api:ruststream_sqs_sns::SqsError::NotFifo). При доставке группа приходит в
`PARTITION_KEY_HEADER`, и по ней выбираются [партиции воркеров](../lanes.md).

Тема FIFO в SNS доставляет только в очереди FIFO, и по пути сообщение сохраняет свою группу, как
показывает страница [Темы](topics.md).

Это поведение самого Amazon SQS
([основные термины FIFO](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/FIFO-key-terms.html),
[идентификатор группы сообщений](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/using-messagegroupid-property.html),
[идентификатор дедупликации](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/using-messagededuplicationid-property.html)).
