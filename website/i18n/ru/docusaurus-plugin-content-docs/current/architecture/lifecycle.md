# Жизненный цикл

[`SqsBroker::new`](api:ruststream_sqs_sns::SqsBroker::new) записывает конфигурацию, connect
загружает конфигурацию AWS, старт открывает задачу приёма на каждую очередь, а завершение работы
закрывает соединение.

<Diagram name="lifecycle" words={words} />

`new`, `endpoint`, `region`, `test_credentials` и `from_config` не выполняют ввода-вывода, поэтому
билдер сервиса остаётся синхронным. Копия брокера разделяет с ним соединение: так хук старта
получает соединение, которое открыл рантайм. Рантайм подключает брокер при старте приложения.

Подключение загружает конфигурацию AWS через цепочку SDK по умолчанию, с конечной точкой и регионом,
которые называет брокер, и задаёт тайм-аут 25 секунд на попытку, больше 20-секундного длинного
опроса. Брокер из `from_config` берёт свой `SdkConfig` как есть, вместе с тайм-аутами. Затем
подключение собирает клиенты SDK. Учётные данные
SDK получает лениво, при первом запросе. В сервисе этот запрос - `GetQueueUrl` первой подписки,
поэтому с неверными учётными данными старт прерывается на подписке.

Сначала проверяется [`SqsQueue`](api:ruststream_sqs_sns::SqsQueue) каждой подписки: пустое имя,
ожидание дольше 20 секунд или видимость вне диапазона от одной секунды до 12 часов дают ошибку
[`SqsError::InvalidQueue`](api:ruststream_sqs_sns::SqsError::InvalidQueue) ещё до обращения к
AWS. Затем подписка получает адрес очереди или, при `create_if_missing`, создаёт очередь. Она
записывает политику перенаправления, когда регистрация объявляет `max_attempts` и `dead_letter`.
Если дескриптор не называет тайм-аут видимости, она читает собственный тайм-аут очереди. Затем
она запускает задачу приёма.

Ошибка получения попадает в поток подписки как элемент. Если очереди больше нет, задача приёма
завершается, а после любой другой ошибки ждёт одну секунду до следующего получения.

Завершение работы помечает соединение закрытым и возвращает `()`: клиентам SDK нечего закрывать и
нечего сбрасывать. Издатель, созданный до завершения работы, после него возвращает
[`SqsError::NotConnected`](api:ruststream_sqs_sns::SqsError::NotConnected).
