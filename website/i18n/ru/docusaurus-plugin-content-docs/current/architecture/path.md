# Путь

Путь сообщения SQS через сервис RustStream: получение, доставка, обработчик, ответ и удаление, по
одному сообщению или пакетами.

<Diagram name="path" words={words} />

Задача приёма запрашивает десять сообщений за одно получение, со всеми атрибутами сообщения и
системными атрибутами, и ждёт до 20 секунд. Тайм-аут видимости она называет, только когда его
называет дескриптор. Длинный опрос, который закончился ничем, ничего не выдаёт, поэтому пакет
никогда не бывает пустым. Канал вмещает один пакет, поэтому задача приёма опережает обработчики
не больше чем на одно получение.

Каждое сообщение становится [`SqsMessage`](api:ruststream_sqs_sns::SqsMessage). Тело копируется
из ответа SDK, а атрибуты сообщения становятся заголовками, вместе с группой сообщений и счётчиком
получений. Доставка также запускает продление своей видимости. На сообщение приходится несколько
выделений памяти, а во что обходится одно сообщение, публикует страница
[Бенчмарки](/architecture/benchmarks/).

Подписка, которая обрабатывает сообщения по одному, разбирает пакет и выдаёт его сообщения по
порядку. Пакетная подписка запрашивает собственный размер, но не больше десяти, и её обработчик
принимает весь пакет за один вызов. Каждое сообщение пакета всё равно удаляется отдельным вызовом.

Ответ кодируется в буфер, который цикл диспетчеризации использует повторно.
[`SqsPublisher`](api:ruststream_sqs_sns::SqsPublisher) берёт этот буфер телом одного вызова
`SendMessage`, а [`SnsPublisher`](api:ruststream_sqs_sns::SnsPublisher) - телом одного вызова
`Publish`. Адрес очереди или ARN темы разрешается один раз и кешируется.

Доставка завершается после ответа. Каждое завершение проходит через клиенты SDK того рантайма,
который его выполняет, а что делает каждый исход, показывает страница [Завершение](settlement.md).
